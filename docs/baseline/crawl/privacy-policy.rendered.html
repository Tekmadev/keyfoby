📋1. Introduction

Welcome to KeyFoby. This Privacy Policy explains how we collect, use, disclose, and safeguard your information when you use our mobile application (the "App") and related services.

KeyFoby is a professional mobile business management application designed specifically for locksmith businesses. The App helps you track sales, expenses, inventory, and business analytics.

By using our App, you agree to the collection and use of information in accordance with this Privacy Policy. If you do not agree with this policy, please do not use our services.

🔐4. Data Storage and Security

4.1 Where We Store Your Data

  • ✓All data is stored in Supabase's secure PostgreSQL database
  • ✓Data is encrypted in transit using HTTPS/TLS encryption
  • ✓Data is encrypted at rest by our infrastructure provider
  • ✓Data centers comply with industry-standard security certifications
  • ✓Data may be stored in multiple regions for redundancy and reliability

4.2 Security Measures

🔒

Row Level Security

Only you can access your data - isolated by User ID

🔑

Secure Authentication

Tokens are securely stored on your device

🛡️

Password Protection

Passwords are hashed and never stored in plain text

🌐

HTTPS Encryption

All API communications use secure HTTPS

🔐

OAuth Security

Google passwords are never stored

📱

Device Security

Authentication credentials secured on device

4.3 Data Retention

  • •User data is retained for as long as your account remains active
  • •You can request account deletion at any time through the App settings
  • •Upon deletion, all associated data will be permanently removed
  • •Some data may be retained in backups for up to 30 days before permanent deletion
