# KeyFoby — Brand Brief

## Summary

**KeyFoby** is a Hamilton, Ontario–based mobile automotive key and key fob service focused on fast, reliable help for drivers who need a replacement key, a spare, programming, or urgent lockout assistance.

## Brand identity

- **Brand name**: KeyFoby
- **Legal name**: KeyFoby Inc
- **Tagline**: Lost Keys? Need a Spare? We've Got You.
- **Short description**: Custom key fobs for cars and homes – built with speed and precision.
- **Positioning**: Local, mobile automotive key specialists offering same-day help when possible, with emergency availability messaging.

## Audience

Primary customers are vehicle owners who:

- Lost their keys (including all keys lost)
- Need a spare key/fob (duplication / add key)
- Need programming (remote, smart key, transponder)
- Need urgent lockout help

## Services (customer-facing)

KeyFoby provides automotive key services including:

- **Car key replacement**
- **Car key duplication / spare key creation**
- **Key fob programming / remote programming**
- **Smart key programming**
- **Transponder key services**
- **All keys lost / stolen (automotive)**
- **Emergency lockout**
- **Key fob shell replacement**

## Value proposition (why KeyFoby)

- **Fast service**: many duplications positioned as ~15–30 minutes.
- **Mobile-friendly**: easy quote requests and communication; mobile service where possible.
- **Secure process**: messaging emphasizes licensed & insured service.
- **Personalization**: engraving, color options, and key chains (as described in brand data).

## Brand voice

- Friendly, calm, professional, efficient
- Clear about next steps and requirements
- Urgency-aware for lockouts/all-keys-lost, without overpromising

## Warranty (high-level)

- **Warranty period**: 3 months on key fob services.
- **Key requirement**: customer must test all functions on-site before the technician leaves.
- **Covered (summary)**: fob not working, car won’t start with provided fob, lock/unlock not working (when caused by the service).
- **Common exclusions**: water/physical damage, tampering/third-party repairs, dead battery, vehicle mechanical/electrical issues, pre-existing issues, and functions not tested on-site.
